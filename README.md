# Bedal 🌍✨

Learn a skill. Share a skill. Meet your people

Bedal is a gamified social skill-swapping platform designed to help people connect through skills, hobbies, experiences, and real-world meetups.

Instead of simply matching people based on profiles, Bedal encourages users to teach what they know, learn what they want, and build meaningful connections through skill exchange.


🚀 About Bedal

Bedal is being built to make learning and social connection more interactive.


Users can:

🎯 Discover people based on skills and interests

🎥 Share short skill videos

🤝 Invite people to skill exchanges

📅 Manage meetup availability

💬 Chat with other users

👤 Build a personalized profile

☕ Create their own virtual My Café

🏆 Complete quests and progress through levels

🪙 Earn and use Bedal Time Tokens

🌍 Connect with locals, expats, students, tourists, and hobbyists

📍 Discover communities and skill hubs

The goal is to turn skill exchange into a social experience rather than a traditional learning platform.


🎮 Core Concept

Bedal is built around a simple idea:
Everyone knows something. Everyone wants to learn something.
For example:

Someone knows Python but wants to learn photography.
Another user knows photography but wants to learn Python.

Instead of paying for a traditional class, Bedal allows them to connect and exchange their time and skills.

✨ Main Features

🏠 Home
The Home feed allows users to discover short-form skill content from the Bedal community.
Users can:
Watch skill reels
Discover new skills
Invite users
View availability
Report inappropriate content
See Bedal Time balances

🔎 Explore
Explore helps users discover people and skills.
Features include:
Skill discovery
Search
Trending skills
Find a Mentor
Find a Learner
Skill leaderboards
Skill detail pages
Active skill reels
Mentor/Guru directories

👤 Profiles
Each user can create a personalized Bedal profile.
Profiles can include:
Profile picture
Username
Character/avatar
Background
Skills
Café Wall
Guilds
Followers
Following
Level and EXP
Occupation
Optional age
Optional location
Optional gender/nationality visibility
Meetup availability

Users can also manage their profile schedule and availability.

☕ My Café
My Café is a personal space where users can show more of their personality.
It can include:
Music
Short voice bio
Meetup information
Ratings
Meetup count
Personal content

🤝 Skill Exchange
Bedal's main interaction is based around exchanging skills and time.
Users can specify:
Skills they can teach
Skills they want to learn
Bedal Hours they are willing to spend
Preferred meetup partners
Availability

📅 Scheduling
Users can manage their availability through a private calendar.
Other users only see the information needed to arrange a meetup, such as:
Available
Busy
Free time slots
Private calendar details remain private.

💬 Chat
Bedal includes social communication between users.
Chat is organized into
Learners
Hobbyists
Groups
The chat experience is designed around skill exchange and community interaction.

🏆 Gamification
Bedal uses gamification to encourage participation.
Users can:
Earn EXP
Level up
Complete quests
Earn Bedal Time Tokens
Participate in community activities
Build their reputation
New users begin at Level 1.

🪙 Bedal Time
Bedal uses a time-based exchange system.
Instead of making every interaction about money, users can exchange their time and knowledge.
For example:
1 Bedal Hour
can represent one hour of teaching or learning.
This creates a simple way for users to contribute to the community while receiving value in return.
